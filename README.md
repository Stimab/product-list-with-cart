# Product List with Cart

A responsive product shopping interface built with HTML, CSS and JavaScript. It uses local product data and provides a functional cart experience.

## Features

- Browse products dynamically from JSON data
- Add products to the cart
- Increase or decrease quantities
- Remove products
- View the current cart total
- Confirm an order through a modal
- Start a new order and reset the cart
- Responsive mobile and desktop layouts

## Tech Stack

- HTML5
- CSS3
- JavaScript
- JSON

## What I Practiced

This project strengthened my understanding of arrays and objects, DOM manipulation, event handling, state management, dynamic rendering and reusable UI logic.

## Run Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Start it with a local development server.
4. Open the local URL in your browser.
